# 📌 Project Overview

    Viral Trend Analyzer is an AI-powered system designed to analyze social media data, detect patterns behind viral trends, and help users better understand the potential of emerging content. The project combines Machine Learning, Deep Learning, and an interactive dashboard to turn complex social media data into clear and useful insights.



# 🎯 Problem & Project Goal :

Social media platforms are constantly flooded with new content and emerging topics, but only a small portion of them develop into genuine and sustainable trends. Distinguishing a truly growing trend from a short-lived or artificially amplified wave can be challenging for content creators and social media analysts.

Viral Trend Analyzer is designed to analyze social media data and identify patterns associated with the emergence and growth of trends. Using Artificial Intelligence and Machine Learning, the project examines content characteristics, views, user engagement, and other relevant features to better understand and analyze important trends.

Our ultimate goal is to transform raw social media data into meaningful and actionable insights, helping content creators better understand the current state and potential of a trend before making decisions about content creation or publication.


# ⚙️ Approach & Implementation :

To turn this idea into a practical tool, we designed a **user interface (UI) and interactive dashboard** to present the analysis results in a clear and accessible way. The dashboard allows users to explore trend-related information, identify important patterns, and interact with the results generated by the models.

In this project, we used **four independent datasets** to evaluate AI-based approaches for viral trend analysis. For all four datasets, we used **the exact same Machine Learning model and the exact same Deep Learning model**, with identical model structures and architectures. Therefore, the same two fixed models were trained and evaluated across four different datasets. The only factor that changes between these experiments is the **dataset and its corresponding features**.

This structure was chosen to allow us to examine the impact of the data itself more accurately. By keeping the models, architectures, and training approaches unchanged, differences in the results can be attributed more directly to variations in the datasets, their features, and their distributions. This makes the comparison between datasets more consistent and allows us to observe how the same model responds to different types of data.

At the same time, applying the two fixed models across all four datasets allows us to compare the behavior of **Machine Learning and Deep Learning** under different data conditions. Therefore, the goal is not simply to identify the model with the highest accuracy. We also aim to examine how stable each model remains when the dataset changes, how much its performance improves or decreases, and which types of data are more suitable for each approach. In this way, the four datasets provide four different conditions for evaluating the same models and give us a clearer understanding of their overall behavior.

The **Deep Learning** component of the project also goes beyond numerical and structured data. In addition to working with datasets containing numerical and tabular information, we created a **manually collected image-based dataset**. This allows the system to analyze visual characteristics alongside traditional data and provides a broader perspective on the features associated with viral content.   


# 🛠️ Technologies & Libraries :

### 🤖 Machine Learning

**XGBoost**  
XGBoost is the main machine learning algorithm used in our project. As an advanced gradient boosting method, it builds decision trees sequentially and improves the model by reducing the errors made by previous trees. It is particularly effective for structured and tabular data. We also used regularization and tuning parameters such as max_depth, subsample, and reg_lambda to control model complexity and improve generalization.

**Scikit-learn**  
Scikit-learn was used for the core machine learning workflow, including:
- train_test_split — dividing the data into training and testing sets.
- StandardScaler — standardizing numerical features when required by the modeling pipeline.
- accuracy_score — evaluating classification performance on the test data.

**Pandas & NumPy**  
- Pandas — loading and processing CSV datasets, handling missing values, and performing feature engineering.
- NumPy — numerical operations, array manipulation, and preparing data for model training.

**Matplotlib & Seaborn**  
These libraries were used for exploratory data analysis and visualization, including feature distributions, correlation analysis, and model performance plots.

---

### 🧠 Deep Learning

**TensorFlow & Keras**  
TensorFlow and Keras form the main framework for building and training our neural network models. They provide the flexibility needed to design the architecture, train the model, and work with image-based data.

**MobileNetV2**  
MobileNetV2 is used as a pretrained feature extractor for image analysis. Its lightweight architecture makes it suitable for extracting high-level visual features while keeping computational requirements relatively low.

**ImageDataGenerator**  
Keras ImageDataGenerator is used to load and preprocess images and apply data augmentation techniques such as rotation, zoom, shifting, and horizontal flipping. This increases the diversity of the training data and helps the model generalize better.

**preprocess_input**  
The MobileNetV2 preprocess_input function is used to prepare image pixel values in the format expected by the pretrained network.

**EarlyStopping**  
EarlyStopping monitors the validation performance during training and stops the process when the model no longer shows meaningful improvement. This helps reduce unnecessary training and limit overfitting.

**ReduceLROnPlateau**  
ReduceLROnPlateau automatically reduces the learning rate when validation performance stops improving, helping the model continue training with smaller updates and achieve better convergence.

**GlobalAveragePooling2D**  
GlobalAveragePooling2D converts the feature maps produced by MobileNetV2 into a compact fixed-size feature vector, reducing dimensionality before the final classification layers.

**Dropout**  
Dropout is used as a regularization technique by randomly disabling a portion of neurons during training. This reduces over-reliance on specific neurons and improves the model's ability to generalize.

**Dense Layers**  
Dense layers are used to learn nonlinear combinations of the extracted features. The final classification layer produces the probability of the target classes, such as viral or non-viral content.

---

### 🖼️ Image Dataset Processing

For the manually collected image dataset, we rely **exclusively on Deep Learning** using the MobileNetV2 architecture. Unlike structured/tabular data, image data requires neural network-based feature extraction and classification, which is why Machine Learning models like XGBoost are not applied to this dataset.

The project also includes a fully interactive web-based dashboard designed to turn the AI analysis into a practical user experience.

### 💻 Local & Serverless Execution

The frontend is designed to run locally without requiring a dedicated backend server for its interface features. By combining pure web technologies with the AI components, the project provides an interactive environment for exploring and presenting viral trend analysis results.


# 🚀 How to Run :

1. Install the Required Libraries
First, install the Python dependencies required for the machine learning and deep learning components. If the project includes a requirements.txt file, run:
pip install -r requirements.txt
This installs the main libraries used for data processing, model training, and image analysis.
2. Prepare the Datasets
Place the required datasets in the appropriate project directories. The project uses both structured/tabular datasets and a manually collected image dataset for the different AI components.
Make sure the dataset paths used in the Python scripts match the actual location of the files before running the models.
3. Run the AI Models
Run the Machine Learning and Deep Learning scripts or notebooks to train and evaluate the models. The Machine Learning pipeline processes structured data, while the Deep Learning pipeline can also process the image-based dataset using the MobileNetV2 architecture.
After training, the generated results can be used by the dashboard to present the model predictions and analysis.
4. Run the Dashboard
The dashboard is built with HTML, CSS, and Vanilla JavaScript. Open the main HTML file in a modern web browser to access the interface and interact with its features.
The dashboard provides access to the project's visual analysis, trend information, charts, prediction interface, and other interactive components. 



## ⚠️ Limitations & Challenges :

Although the project provides a practical approach to viral trend analysis, several limitations were encountered during development:

Dataset size and diversity: The available datasets do not fully cover all types of social media content, platforms, and audience behaviors. Using larger and more diverse datasets could significantly improve the reliability and generalization of the results.
Differences between datasets: Each dataset has its own structure, feature set, and distribution. These differences can influence model performance and make direct comparison between datasets more complex.
Viral trend complexity: Viral content is affected by many unpredictable factors such as current events, user behavior, platform algorithms, and social context. Therefore, no model can guarantee that a specific piece of content will become viral.
Limited image dataset: The image dataset was collected manually and is relatively small compared to the structured datasets. Expanding it with more diverse and high-quality visual data could improve the performance of the deep learning component.
Dependence on data quality: Model performance is highly dependent on the quality, completeness, and consistency of input data. Issues such as missing values, noise, or biased samples can negatively affect predictions.
Computational requirements: Training deep learning models, especially on image data, requires significant computational resources and time compared to traditional machine learning approaches.
These limitations highlight important directions for future improvement. Expanding dataset size and diversity, integrating additional social media signals, and enriching the visual dataset can make the system more accurate, robust, and scalable.


# 🔮 Future Development Ideas :

- **Trend Competition Analysis:** Compare multiple trends simultaneously to identify which ones have greater potential to attract audience attention and which trends are beginning to lose momentum.

- **What-if Simulation:** Allow users to modify specific features and explore how those changes could affect the trend score. For example, users could examine the potential impact of a 20% increase in engagement rate.

- **Trend Similarity Search:** Allow users to upload new content or an image and find similar examples from previously analyzed trends, then compare their historical performance and behavior.

- **Emerging Trend Prediction:** Instead of focusing only on trends that are already viral, identify topics that are still relatively small but show early signals of rapid growth.

- **Out-of-Sample Evaluation:** Evaluate the models on datasets that were not used during training to determine how well they generalize to unseen data rather than only measuring their performance on the original datasets.
